# Loghi

Metti qui i file e scrivi il nome nella voce corrispondente in `index.html`:

```js
youtube: { name:"YouTube", ..., logo:"logos/youtube.png" },
```

Formati: `png`, `svg`, `webp`. Un quadrato con sfondo trasparente rende
meglio: il riquadro colorato si fa da parte e resta solo l'immagine.

Dove non metti un file resta il segno disegnato, quindi puoi farne anche solo
qualcuno. I file finiscono nel pacchetto da soli, senza toccare `build.sh`.
